Instalação rápida

Como instalar no celular

Use esta página no próprio Android. Baixe o APK, autorize a instalação e ative o dispositivo com o código interno da fazenda.

⬇️ Baixar FarmSafe Coletor
✓ Tenha internet na primeira ativação.
✓ Permita acesso à câmera para ler QR Codes.
✓ Permita localização quando solicitado.
✓ Use data e hora automáticas no Android.
Importante O código interno de ativação deve ser fornecido apenas pela administração da fazenda.
1
Toque em “Baixar APK Android” O arquivo do FarmSafe Coletor será baixado no celular.
2
Abra o arquivo baixado Normalmente ele aparece na barra de notificações ou na pasta Downloads.
3
Autorize a instalação O Android pode pedir permissão para instalar aplicativos de origem externa.
4
Abra o FarmSafe Coletor Depois de instalado, toque no ícone do aplicativo na tela inicial.
5
Ative o dispositivo Informe o código interno da fazenda para liberar os cochos e insumos autorizados.
6
Baixe os dados offline Antes de ir ao campo, atualize os dados do coletor com internet disponível.
Recursos do app

Feito para a rotina real da fazenda

O FarmSafe Coletor foi pensado para ser simples para o tratador, seguro para a gestão e confiável mesmo em áreas sem sinal.

📷

Leitura por QR Code

Identifica o cocho rapidamente, reduzindo digitação manual e erro operacional.

📡

Funciona offline

Registros ficam salvos no aparelho e são enviados quando a internet voltar.

📍

Auditoria GPS

Permite registrar localização, data, horário, dispositivo e cocho abastecido.

🔒

Sem login do tratador

O celular é ativado com código interno. O painel web continua restrito à gestão.

📦

Controle de insumos

Os abastecimentos podem alimentar o consumo de estoque no sistema FarmSafe.

🧾

Histórico local

O operador consegue consultar registros pendentes, sincronizados ou com alerta.

Dúvidas comuns

Informações importantes

Orientações rápidas para instalação, uso em campo e suporte.

O app funciona sem internet?

Sim. O registro fica salvo no celular e sincroniza quando houver conexão.

O tratador precisa de senha?

Não. O dispositivo é ativado com código interno da fazenda.

Precisa instalar pela Play Store?

Nesta versão, a instalação é feita por APK oficial distribuído pela FarmSafe.

Como atualizar o app?

Quando houver versão nova, a administração poderá baixar o novo APK oficial.

E se o QR Code não abrir?

Atualize os dados offline do coletor e confirme se o cocho está ativo no sistema.

Quem deve instalar?

A instalação deve ser feita pelo responsável técnico, suporte ou administração da fazenda.

Precisa de ajuda para instalar?

Fale com a equipe FarmSafe para receber orientação sobre instalação, ativação do dispositivo e uso em campo.
